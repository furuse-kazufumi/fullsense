## 2. 章立て(honest saga の弧)

各章 = 【目的】【正直な急所(honest beat)】【メディア】【数値=検証ステータス】。★=山場。

**0. 3 行まとめ(結論先出し)**
- 筋肉の手 × 箸 → 正しい持ち方 + **6 秒の firm hold** 達成。筋 ON/OFF の ablation で「本物の握力か / ただの楔か」を判定。
- だが **lift(持ち上げ)を足すと約 2 秒で落とす**「掴めるのに運べない」壁。しかも道中の「成功」は何度も **楔 / 自重の誤読 / 射出** だった。
- 価値はタスクの新しさではない(箸把持は既出)。**失敗を段階に帰属する物差し + ablation で自分の嘘を殺す正直さ**に置く。

**1. 用語(先に地図)** — §3 のグロッサリを表で。

**2. なぜ「筋肉の手」で箸か** 【動機=義手/feeding】【前日譚 779b「トイでは学習が手作りに負けた/でも手が無かった」→ 宿題=本物の手】【先行研究(survey 結果を反映)】

**3. ★手そのものの罠 — 母指が届かない** 【evis native 手を「指ゼロのミトン」と誤診→実は 38 筋の関節手だった訂正。さらに深い真実: **母指が対向できない**(骨格上 1.76cm しか届かず、棒径 0.64cm に不足)=制御でなく骨の問題】【「母指手術」= 母指分節 1.6 倍延長で対向可能に】【メディア: chop_thumb_compare.mp4 / chop1_thumb_compare.gif】

**4. ★楔 artifact — 「持てた」が幾何の罠だった** 【筋 OFF(ablation)でも箸が保持される=筋の握力でなく指の隙間に**幾何で楔止め**されていただけ。ablation こそが本物と偽物を分ける】【4 ゲート検証ハーネス(A 手放し / B 保持 / C force-closure ε / D 摂動)。**25 エージェントの敵対レビューが第1版の 6 欠陥(私自身の Gate D スピン計測の座標系バグ含む)を摘発**】【メディア: chop_compare_onoff.mp4 / compare_onoff_..._720p】

**5. ★二点つまみの確立 — ロバスト圧が「正しい形」を副産物で生んだ** 【あらゆる報酬調整が失敗した「親指先 + 人差し指先の二点つまみ」を、**摂動に耐えろという圧**が副産物で獲得】【best_hold_robust_long: 8s ゲート PASS / 二点つまみ(親指 37% 人差し指 53%)/ held-out 摂動 20/20】【honest: 窓 artifact(8s ロバストだが 12s で崩壊、physfix は逆)を長窓再進化で統合】【メディア: chop_hold8s.mp4 / chop3_hold8s.gif / showcase_..._720p】

**6. ★掴めた…と思ったら、自重を握力と誤読していた** 【接触力を「握力」と読んでいたが、実は**皿の反力=食片の自重そのもの**。箸のみの接触に絞ると **F=0.00N・接触0=箸は食片に一度も触れていなかった**。lift の +mm も箸が持ち上げたのではない】【射出の機序: t=0 で既に貫入(自重の 10〜90 倍)+ 横方向に拘束なし →「石鹸を握ると飛ぶ」】【メディア: chop_eat_fail.gif / chop5_eat_fail.gif / evis out png】

**7. なぜ掴めないかを、推測でなく実測で** 【箸先幾何の破綻(TIPGAP 5.85mm vs ロッド半径 3.2mm →顎の隙間が物理的に無い)/ 仰角がハードコード(fwd[2]=-0.28=-15.78°)で腕を振っても変わらなかった → tip-drop 0 で滑落 -200mm→-7mm 解決 / 水平開き ROLL90 で符号反転の罠】【3 つの仮説を実測で反証した過程】

**8. ★firm capture 成立 — 6 秒挟み続ける** 【決め手 = 水平スライドを作らず **手を最初から口元へ寄せる(--myo-dy 0.7、口まで 937→242mm)** + 上下両ロッドに受け → 2 点が終端まで残る】【保持 6000ms / 接触 4〜5 点 / F 0.52→0.99N / 軸 +4mm(箸先)】【メディア: chop_closed_loop_v6.mp4 / chop2_closed_loop.gif】

**9. ★でも運べない壁 — 掴めるのに、運べない** 【lift を入れた瞬間 ~2 秒で落とす(超低速でも)。**回転は grip を壊す / 並進は壊さない**(筋が関節を跨ぐため)。自由度を 1 つ足すだけで壊れる】【皿 A→B「達成」は**皿 B を 5cm 下げたズル**だったと自己摘発(食片が沈む先に皿を合わせた)。同一高さでは失敗】【「持ち方と動作を同時最適化すると持ち方が犠牲になる」共進化問題】【メディア: chop_plate_to_plate.mp4(ズルの記録)/ chop_pickplace_e2e.mp4(数値は near-pass だが映像で未把持)】

**10. 横道 — 両眼で距離を測る** 【頭に瞳孔間 64mm の平行ステレオ。視差 29.9px → 推定 889.3mm / 真値 873.6mm、誤差 +1.8%。特権は「緑を色で抽出」1 つだけ、幾何は本物】※軽い箸休め章。react で「入れる/落とす」判断。

**11. なぜ「未達」を書くのか(gift-to-reader)** 【映像を必ず見る鉄則が false success を何度も摘発した/ ablation・force-closure・held-out・窓積分は全部自分の楽観を殺す仕掛け/ 掴めていないものを掴めたと言わない = このプロジェクトの核】

**12. 次回に続く(cliffhanger)** 【壁の攻め方: (a)把持と動作の筋を構造分離して end-to-end 長時間共進化(GPU/MJX 大量並列)(b)接地点補正(capture point)を横バランスに(c)触覚(薬指が荷重 81% を負う「柱」)を観測に】

## 3. グロッサリ(用語 → かみくだき)ドラフト

| 用語 | かみくだき |
|---|---|
| 筋骨格モデル(musculoskeletal model) | モータでなく**筋肉の収縮**で関節を動かすシミュレーション。人体に近いが制御が難しい |
| force-closure(力の閉じ, 把持の安定条件) | 物体をどの向きに押しても指/箸が押し返せる=本当に「掴めている」状態。数値は ε(Ferrari-Canny)で測る |
| ablation(切除テスト) | **筋肉を全部 OFF にして落ちるか**を見る。落ちれば筋で握っていた証拠。落ちなければただの幾何の楔 |
| 楔 artifact(wedge artifact) | 指の隙間に物が**幾何的に挟まっているだけ**なのを「握れた」と誤読すること。ablation で暴ける |
| firm capture(しっかり掴む) | 触れるだけでなく、動かしても保持できる本物の把持 |
| condim(接触の自由度) | MuJoCo の接触が持つ次元。3=滑り摩擦だけ / 6=ねじれ・転がり摩擦も。丸い箸で物が回って逃げるのを止めるのに要る |
| 母指対向(thumb opposition) | 親指の腹を他の指へ向き合わせること。これが無いと精密つまみ(箸)は原理的に不能 |
| held-out(訓練外テスト) | 学習に一切使っていない設定での成績。汎化の唯一の証拠 |
| 窓積分(windowed impulse) | 一瞬の接触力でなく一定時間で均した力。ソルバのスパイクを「成果」と偽らない衛生 |
| 共進化(co-adaptation) | 把持と運搬動作を同時に最適化すると片方が犠牲になる問題。この記事の壁の正体 |
| 射出(ejection) | 上下から圧迫された物が横の拘束なしで飛び出す現象(石鹸を握ると飛ぶのと同じ) |
| capture point | 倒れ/ずれを一歩の足位置(or 接地点)補正で吸収する制御の考え方。横バランスの鍵 |
