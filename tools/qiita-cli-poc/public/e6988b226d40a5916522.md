自宅のLLM実験機に **NVIDIA GeForce RTX 5090** を入れた。効果がどれくらいかを、**まったく同じアーキ探索（NAS・751 evals・同一設定・同一 seed）を CPU と GPU で最後まで回して**実測した。細かい理屈は抜きで、まず結果から。

## 結論：6時間6分 → 5分9秒（約71倍）

![同じNAS探索を回した時間：CPU 6時間6分 vs RTX 5090 5分9秒 = 71倍](https://raw.githubusercontent.com/furuse-kazufumi/fullsense/main/docs/articles/assets/gpu_effect_rtx5090/hero_speedup.png)

## 動画で見る（同じ探索・経過時間で比較）

GPU が全 751 evals を完走した時点（5分9秒）、CPU はまだ全体の **約1.4%**（≈11 evals）。そのあと CPU が最後まで行くのに合計 6時間6分かかる。

![経過時間で見る速さ：GPUが完走してもCPUは1.4%](https://raw.githubusercontent.com/furuse-kazufumi/fullsense/main/docs/articles/assets/gpu_effect_rtx5090/gpu_race.gif)

高画質版（mp4）: <https://raw.githubusercontent.com/furuse-kazufumi/fullsense/main/docs/articles/assets/gpu_effect_rtx5090/gpu_race.mp4>

## 速くなっただけ。答えは変わっていない

CPU と GPU で得られた frontier はほぼ完全に重なる（hypervolume **150.483 vs 150.483**、差 ≒ 0.0005% は浮動小数点の丸め順序＝device 依存）。**GPU にしても結果は変わらない** —— これがこの図の主眼。

![CPUとGPUのmemetic frontierが重なる](https://raw.githubusercontent.com/furuse-kazufumi/fullsense/main/docs/articles/assets/gpu_effect_rtx5090/pareto_match.png)

## 1回の順伝播はどれだけ速いか

モデルサイズと文脈長を変えて実測。GPU は float32 で 10〜30倍、bfloat16 なら最大 約67倍。

![順伝播の速度倍率グリッド](https://raw.githubusercontent.com/furuse-kazufumi/fullsense/main/docs/articles/assets/gpu_effect_rtx5090/forward_grid.png)

## 実測環境と正直な内訳

- GPU: NVIDIA GeForce RTX 5090 / CPU: Intel Core Ultra 7 270K（24コア）/ RAM 127GB / PyTorch 2.11+cu128
- 比較は**同一スクリプト・同一 seed**、時間は探索コードが記録する `elapsed_s`。CPU=float32、GPU=float32（apples-to-apples）。
- bfloat16 は**小モデルでは float32 と変わらない**（0.5B・256トークンでは bf16 ÷ f32 ≒ 1.0＝上乗せ無し。ただし float32 の時点で既に対CPU 10倍）。効くのは大モデル×長文脈（1.5B・1024トークンで対CPU 約67倍）。
- **端末間の71倍が単発順伝播の10〜30倍より大きい理由**：探索の1評価は多数の窓（fast K=8ペア＋ホールドアウト12）を最長4096文脈で回すので、GPU のバッチ処理が効く。単発1回より throughput 利得が大きく、加えて6時間走る CPU 側のオーバーヘッドも乗る。71倍は「単発の生の演算速度」ではなく「探索まるごとの実時間」の比。
- CPU↔GPU の hypervolume 差 0.0005% は手法差ではなく浮動小数点の丸め順序（device 依存、数十 ULP）。
- **+42.6% は選択集合上の hypervolume 利得**（ホールドアウトの HV 利得も 43%・CI[42.5,43.8]・p_win=1.0 で頑健）。ただし memetic-vs-greedy の厳密 verdict はホールドアウトで「選択楽観 > ノイズ床」により**保留**扱い。この記事の主眼は手法の当否ではなく「**GPU でも同じ数値・同じ frontier が出る**」こと。NAS の中身（メモリ削減率×品質 frontier を進化計算で探す話）は別記事に譲る。

要するに：**手法も答えも同じまま、待ち時間だけが桁で消えた。** これが GPU を積んだ効果。
