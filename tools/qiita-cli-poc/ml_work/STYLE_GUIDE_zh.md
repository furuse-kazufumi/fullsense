# 中文(简体)翻译风格指南 — 「自宅ヒューマノイド運動会」文章

## 任务
将日语 Qiita 长文翻译为面向全球中文工程师读者的自然、生动的简体中文版。不是逐字直译,而是"同一作者写的中文版"。

## 语气
- 轻松幽默、自嘲但技术严谨。原文是"带喜剧感的严肃技术文"。目标语感 = 高质量的知乎/掘金长文。
- 绝不自夸。诚实披露(honest disclosure)是核心原则: 保留所有限定语、注意事项、失败承认,语气强弱**不得增强主张、不得弱化失败**。
- 不居高临下(禁止"连新手都能…"式表述)。
- 对北京人形机器人运动会保持敬意与善意 — 文章的立场是"受到激励",不是竞争或比较优劣。标题的「うらやましい」译为"羡慕"(正面语义)。

## 硬性规则
1. **图片 URL 逐字节不变。** 所有 `![alt](https://raw.githubusercontent.com/...)` 的 URL 保持原样。alt 文本和图片下方的 `*...*` 斜体说明行要翻译(保留斜体格式,保留"(仿真环境实测)"式诚实标注)。
2. **代码块不变**(``` 围栏及内容逐字保留)。表格结构不变(列数相同);单元格文字翻译,但 op 名、文件名、命令、数字、单位保持原样。
3. **数字、单位、日期不变。** M 记号说明保留(M = 百万训练步,不是米)。
4. **脚注**: `[^id]` 的 id 不变;脚注正文翻译;引用文献标题/URL 逐字保留。日语文献脚注末尾加 "(日文)"。
5. **标题**: 翻译,编号保留(如 `## 6.5.1`)。
6. **致谢/许可原样保留精神**: NASA/JPL-Caltech/Univ. of Arizona、EHT Collaboration (CC BY 4.0)、Pexels (Barbara Olsen)、CMU mocap 的 NSF EIA-0196217 英文句子原样保留、LAFAN1 CC BY-NC-ND(非商用)、MVTec HALCON 商标声明。
7. **GIF 内嵌文字是日语** — 保持不动;首个 chunk 的开头加一句注: "图内文字为日语原版,含义见图下说明。"
8. 专有名词不翻译: Fullseye, Studio, evis, hillco, MuJoCo, MJX, brax, LAFAN1, Menagerie, walk13d, ChopMimic, Unitree G1, Barkour 等。
9. 使用**简体中文**、中国大陆技术社区惯用译名(强化学习、模仿学习、奖励函数、域随机化、步态、仿真等)。
