# 한국어 번역 스타일 가이드 — 「자택 휴머노이드 운동회」 기사

## 미션
일본어 Qiita 장문 기사를 한국 엔지니어 독자를 위한 자연스럽고 생동감 있는 한국어판으로 번역한다. 직역이 아니라 "같은 저자가 쓴 한국어판".

## 톤
- 가볍고 유머러스하며 자기비하적이지만 기술적으로 엄밀. 원문은 "코미디 감각의 진지한 기술 글". 목표 = 잘 쓴 기술 블로그 장문의 어조. 문체는 해요체가 아닌 **~다/~했다 체(평서형)** 를 기본으로 하되, 독자에게 말을 거는 부분은 자연스럽게.
- 절대 자랑하지 않는다. 정직한 공개(honest disclosure)가 핵심: 한정 표현·주의사항·실패 인정을 그대로 유지 — **주장을 강화하거나 실패를 완화하지 않는다**.
- 잘난 체하는 표현 금지("초보자도 할 수 있는…" 류).
- 베이징 휴머노이드 로봇 운동회에 대한 존중과 호의를 유지 — 기사의 입장은 "자극을 받았다"이지 경쟁이 아니다.

## 필수 규칙
1. **이미지 URL 바이트 단위로 불변.** 모든 `![alt](https://raw.githubusercontent.com/...)` URL 그대로. alt 텍스트와 이미지 아래 `*...*` 이탤릭 캡션은 번역(이탤릭 형식 유지, "(시뮬레이션 실측)" 식 정직 태그 유지).
2. **코드 블록 불변**(``` 펜스와 내용 그대로). 표 구조 불변(열 수 동일); 셀 텍스트는 번역하되 op 이름, 파일명, 명령어, 숫자, 단위는 그대로.
3. **숫자, 단위, 날짜 불변.** M 표기 설명 유지(M = 백만 학습 스텝, 미터가 아님).
4. **각주**: `[^id]` id 그대로; 각주 본문 번역; 인용 문헌 제목/URL 그대로. 일본어 문헌 각주 끝에 "(일본어)" 추가.
5. **제목(헤딩)**: 번역하되 번호 유지(예: `## 6.5.1`).
6. **크레딧/라이선스 원문 존중**: NASA/JPL-Caltech/Univ. of Arizona, EHT Collaboration (CC BY 4.0), Pexels (Barbara Olsen), CMU mocap의 NSF EIA-0196217 영문 문장 그대로, LAFAN1 CC BY-NC-ND(비상업), MVTec HALCON 상표 문구.
7. **GIF 안에 새겨진 텍스트는 일본어** — 그대로 둔다; 첫 chunk 도입부에 한 문장 추가: "그림 안 텍스트는 일본어 원본이며, 의미는 캡션에 있습니다."
8. 고유명사는 번역하지 않는다: Fullseye, Studio, evis, hillco, MuJoCo, MJX, brax, LAFAN1, Menagerie, walk13d, ChopMimic, Unitree G1, Barkour 등.
9. 한국 기술 커뮤니티 관용 표기 사용(강화학습, 모방학습, 보상 함수, 도메인 랜덤화, 보행, 시뮬레이션 등). 외래어는 국립국어원 표기보다 개발자 관용 표기 우선(예: 시뮬레이션, 모캡).
